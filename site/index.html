INSTALAÇÃO

WINDOWS

  1. Descompacte o zip (botão direito → Extrair tudo).
  2. Copie a pasta .vst3 do plugin para C:\Program Files\Common Files\VST3\
  3. Abra o Cubase (ou sua DAW).

MAC

  1. Baixe o zip. O Mac descompacta sozinho.
  2. Feche o Cubase.
  3. No Finder, aperte Cmd+Shift+G, cole ~/Library/Audio/Plug-Ins/VST3/ e copie o .vst3 para lá (o AU vai em ~/Library/Audio/Plug-Ins/Components/).
  4. No Terminal, libere o plugin: 
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"DubMastor Big Knob.vst3"
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"FitaEco TE-12.vst3"
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Mastor Roots Keys.vst3"
  5. Abra o Cubase.

O plugin não apareceu? No Cubase, abra Studio → VST Plug-in Manager e faça um novo scan; se ele estiver na lista de bloqueados, clique em Reactivate. Na lista de plugins, o Dub Station aparece como FitaEco TE-12, do fabricante DubMastor. O Mastor Roots Keys é um instrumento: carregue-o numa Instrument Track, não como efeito.
