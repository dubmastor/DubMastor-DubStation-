## Mastor Reggae Chord Machine MRCM-1240 1.5 🟢🟡⚫

- **Novo nome:** o plugin agora se chama **Mastor Reggae Chord Machine MRCM-1240** (no plugin, na DAW, nos arquivos e no MIDI exportado). Os projetos antigos do Cubase continuam abrindo com ele. Apague da pasta VST3 os arquivos antigos (`Mastor Dub Chords Machine MDCM-404.vst3` e/ou `DubMastor Dub Chords.vst3`) para não ficar com dois
- **Configuração inicial:** ao abrir o plugin, só os **acordes 1 e 2** vêm ligados (Am e Dm), com **1/2 compasso** cada. Os acordes 3 e 4 vêm desligados

Continua tudo da 1.4: bubble com o Hammond Roots Percussion, tamanho da nota começando em 1/32, bubble desligado ao abrir, inversões AUTO / FUND / 1ª / 2ª com a sugestão de notas mais próximas, skank de piano M1 com as duas mãos, PREVIEW e MIDI com cada acorde em um canal (cor).

É um instrumento: no Cubase, carregue numa *Instrument Track*.

No Mac, depois de copiar o `.vst3`:
```
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Mastor Reggae Chord Machine MRCM-1240.vst3"
```

## Como instalar
- **Windows:** baixe o `…-Windows-Instalador.exe` e siga o instalador (se o Windows avisar, clique em *Mais informações → Executar assim mesmo*).
- **Mac:** baixe o `…-macOS-Instalador.pkg` (VST3 + AU, Intel e Apple Silicon). Se o Mac bloquear, vá em *Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim*.
- Os zips são para instalação manual. Passo a passo para cada DAW: https://dubmastor.github.io/DubMastor-DubStation-/#instalacao
